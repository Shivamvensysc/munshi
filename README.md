# LiveMunshi — Khata Book (React + TypeScript + Tailwind)

A redesigned, production-quality UI clone of the LiveMunshi khata-book app —
Login, Sign Up, Forgot Password, Dashboard, Add Customer, Khata switcher,
Cross Entry, Transactions, Customer Details and the More/Profile screen.
Same brand colors as the original (deep royal-blue header gradient + violet
primary actions, green/red ledger accents), rebuilt with a cleaner, more
polished visual system.

## Stack
- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4 (via `@tailwindcss/vite`)
- react-router-dom
- lucide-react (icons)

## Getting started
```bash
npm install
npm run dev       # start dev server
npm run build      # production build -> dist/
npm run preview    # preview the production build
```

## Demo login
This is a front-end only prototype — any 10-digit phone number and 4-digit
password will sign you in.

## Structure
```
src/
  components/   Reusable UI: TopBar, BottomNav, Layout, AuthShell, Button,
                TextField, PhoneField, BalanceSummary, CustomerRow, Accordion
  context/      AppContext — in-memory auth + khata/customer state
  data/         Seed/mock data
  pages/        Login, SignUp, ForgotPassword, Dashboard, AddCustomer,
                KhataList, CrossEntry, TransactionPage, CustomerDetail, More
  types.ts      Shared TypeScript types
```

## Design tokens
Colors, fonts and shadows are defined as CSS custom properties inside an
`@theme` block in `src/index.css`, so every `bg-brand-*`, `text-credit-*`,
`text-debit-*`, `bg-violet-*` etc. utility class is generated by Tailwind
directly from the token system — change a value once and the whole app
updates.
